A fast drop-in for csv-reader 1.0.0: reads broken CSV files with byte-identical answers, using a line fast path (one slice + one split per plain line) and a field-by-field slow path only for quoted, stray-CR, or multiline fields. Pure Node.js standard library, no dependencies.

## Run it

```sh
MAKEFUN_INPUT_DIR=<input-dir> MAKEFUN_OUTPUT_DIR=<output-dir> node main.ts
```
